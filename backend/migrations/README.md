# Миграции БД

`env.py` получает настройки/engine и metadata приложения. `script.py.mako` — шаблон
новой миграции. `versions/` содержит линейную историю:

| Ревизия | Изменение |
| --- | --- |
| 0001 | Заявки и адресный справочник |
| 0002 | Районы и обязательная связь здания с районом |
| 0003 | Пользователи, работники, навыки, refresh-токены |
| 0004 | Назначения, комментарии, уведомления |
| 0005 | Время изменения комментария |
| 0006 | Бригады и состав |
| 0007 | Офисы |
| 0008 | Оборудование, склад и позиции заявок |
| 0009 | Тип транспорта работника, backfill walking |
| 0010 | История маршрутов в GeoJSON и квитанции импорта |
| 0011 | Справочник видов работ с нормативами из файла организаторов |

Из backend: `python -m alembic upgrade head`, затем `python -m alembic check`.
Параметры подключения берутся из DATABASE_URL. Проверяйте адрес БД перед ручными
командами; `downgrade` удаляет данные сущностей отменяемой миграции.

Новые миграции 0009/0010 самодостаточны: список значений транспорта зафиксирован
в миграции и не импортируется из меняющегося runtime-enum. Тесты дополнительно
проверяют upgrade заполненной схемы 0008 и сохранение старых полей workers.
