# Комментарии

`ticket_comments` хранит текст, ticket_id, author_id и created_at/updated_at. Текст непустой, до 4000 символов. Правила доступа связаны с доступностью заявки и автором комментария.

| Файл | Ответственность |
| --- | --- |
| `models.py` | TicketComment и ограничения текста |
| `schemas.py` | Валидация текста и представление автора/времени |
| `repository.py` | Запросы комментариев и проверка существования |
| `service.py` | Доступ к заявке, создание и редактирование своих комментариев |
| `router.py` | HTTP-маршруты комментариев заявки |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
