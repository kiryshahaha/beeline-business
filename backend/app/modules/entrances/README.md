# Подъезды

Таблица `entrances`: building_id и number. Номер уникален внутри здания. Ключ (id, building_id) используется локациями, чтобы запретить указание подъезда из другого здания.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Entrance — подъезд и его принадлежность зданию |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
