# Обслуживание: хранение и очистка

`retention.py` описывает, что удаляется и что хранится всегда. Удаляются
непримененные предпросмотры через `PREVIEW_RETENTION_HOURS` после истечения TTL и
доставленные уведомления старше `NOTIFICATION_RETENTION_DAYS` (0 — хранить всегда).
Применённые планы со снимками, маршруты, ревизии плана дня, `work_events`, история
назначений, состояния дня и квитанции импорта не удаляются.

Каждая пачка (500 строк) — отдельная короткая транзакция под общим планировочным
замком; одновременно идёт только один проход (advisory lock `17321, 3`).
`periodic.py` запускает проход внутри backend раз в `RETENTION_INTERVAL_MINUTES`;
`../../../cleanup.py` — ручной запуск (без `--apply` только считает).

| Файл | Ответственность |
| --- | --- |
| `retention.py` | Правила, подсчёт кандидатов, удаление пачками, один проход за раз |
| `periodic.py` | Таймер внутри процесса и запись результата в журнал операций |

Эксплуатация и резервное копирование — [docs/OPERATIONS.md](../../../../docs/OPERATIONS.md).
