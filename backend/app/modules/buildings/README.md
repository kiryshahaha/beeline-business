# Здания

Таблица `buildings`: city_id, street_id, district_id, number и необязательный block. Два составных внешних ключа запрещают смешивать город улицы и района. Номер/корпус уникальны внутри улицы; отсутствие корпуса не позволяет обойти дедупликацию.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Building — общее здание для подъездов и мест обслуживания |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
