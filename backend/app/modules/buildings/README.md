# Здания

Таблица `buildings`: city_id, street_id, service_area_id, number и необязательный block. Составной внешний ключ проверяет, что улица принадлежит городу дома; второй внешний ключ ссылается на зону обслуживания. Номер и корпус уникальны внутри улицы; отсутствие корпуса не обходит дедупликацию.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Building — общее здание для подъездов и мест обслуживания |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
