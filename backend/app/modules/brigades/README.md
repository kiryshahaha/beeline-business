# Бригады

`brigades` связывает название, office_id и foreman_id. Бригадир управляет одной бригадой. `brigade_members` хранит текущих работников; один работник состоит не более чем в одной бригаде. Состав влияет на видимость заявок, пользователей и новых маршрутов.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Brigade и BrigadeMember, уникальность состава |
| `schemas.py` | Создание бригады и замена участников |
| `repository.py` | SQL, чтение участников и проверка связей |
| `service.py` | Проверка ролей бригадира/участников и атомарная замена состава |
| `router.py` | API создания, списка, чтения и состава бригады |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
