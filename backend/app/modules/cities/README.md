# Города

Таблица `cities`: ID и название города. Уникальность названия проверяется без учёта регистра. Город объединяет улицы и районы; удаление используемых записей ограничено внешними ключами.

| Файл | Ответственность |
| --- | --- |
| `models.py` | City — корневая запись адресного справочника |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
