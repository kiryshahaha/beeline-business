# Оборудование и склад

`appliances` — номенклатура с типом, единицей и признаком активности. `appliance_stocks` хранит физический остаток по паре офис/позиция. `ticket_appliances` связывает заявку, позицию, офис и количество. Резерв рассчитывается по planned/in_progress; доступно = остаток − резерв. TOOL не списывается как расходник при завершении.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Три таблицы номенклатуры, остатков и выделения оборудования |
| `enums.py` | ApplianceType: девять типов, включая TOOL и CABLE |
| `schemas.py` | Создание/редактирование, остатки и позиции заявок |
| `repository.py` | Запросы, блокировки остатков и списание |
| `service.py` | Доступ к заявке, проверка количества и свободного остатка |
| `router.py` | API номенклатуры, офисного склада и оборудования заявки |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
