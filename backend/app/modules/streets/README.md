# Улицы

Таблица `streets`: название и city_id. Название уникально без учёта регистра в пределах города. Улица не привязана к одному району: её здания могут находиться в разных районах.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Street — улица и составной ключ для ссылки здания |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
