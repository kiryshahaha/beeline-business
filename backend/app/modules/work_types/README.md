# Виды работ

Таблица `work_types`: название и норматив времени из файла организаторов «Нормативы.xlsx».
Норматив хранится с разбивкой на дорогу, технические работы и документы; `norm_minutes`
вычисляет PostgreSQL как их сумму. Стартовые строки создаёт миграция 0011.
Заявки пока хранят тип работ строкой `tickets.work_type` и на эту таблицу не ссылаются.

| Метод | Путь | Доступ | Ошибки |
| --- | --- | --- | --- |
| GET | `/api/v1/work-types`, `/{id}` | все авторизованные | `404` |
| POST | `/api/v1/work-types` | `observer` | `409` — название занято, `422` — неверные минуты |
| PATCH | `/api/v1/work-types/{id}` | `observer` | `404`, `409`, `422` — итоговый норматив 0 или пустое тело |

`PATCH` меняет только переданные поля; `null` и `norm_minutes` во входных данных отклоняются.
Проверка названия идёт до записи и повторно через уникальный индекс на случай гонки.

| Файл | Ответственность |
| --- | --- |
| `models.py` | WorkType, вычисляемый норматив и ограничения минут |
| `schemas.py` | Ответ, создание и частичное изменение с проверками |
| `repository.py` | Чтение, блокировка строки, вставка и обновление разрешённых столбцов |
| `service.py` | Уникальность названия, положительный норматив, транзакции |
| `router.py` | HTTP и роли: чтение для всех авторизованных, запись для `observer` |

Общий API описан в [backend README](../../../README.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
