# Авторизация и сессии

Вход по логину и паролю выдаёт JWT access и refresh. Пароли проверяются Argon2;
refresh хранится в базе в виде SHA-256 хеша. Ротация погашает исходную запись
условным `UPDATE ... RETURNING` внутри транзакции создания новой пары. Повторное
или одновременное погашение отвечает `401` и не создаёт вторую цепочку.

`JWT_SECRET_KEY` задают явно; конфигурация требует не менее 32 байт и не содержит
рабочего значения по умолчанию. Смена пароля или фактическая смена роли отзывает
все refresh-сессии пользователя. Для каждого access-запроса роль повторно читается
из базы. Матрица API находится в [документе доступа](../../../../docs/ACCESS_CONTROL.md).

| Файл | Ответственность |
| --- | --- |
| `enums.py` | Тип ответа токена bearer |
| `schemas.py` | Контракты login, refresh, logout |
| `repository.py` | Создание и отзыв refresh-токенов |
| `service.py` | Проверка пароля и жизненный цикл токенов |
| `dependencies.py` | Обязательная JWT-авторизация и `require_roles` |
| `router.py` | HTTP-маршруты `/api/v1/auth` |

Общий API описан в [backend README](../../../README.md); миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
