# Авторизация

Вход по логину/паролю выдаёт JWT access и refresh. Пароли проверяются Argon2; refresh хранится в виде хеша и отзывается при ротации. Права при запросе проверяются по текущему пользователю из БД. Конкурентная ротация требует отдельного улучшения, отмеченного в аудите.

| Файл | Ответственность |
| --- | --- |
| `enums.py` | Тип ответа токена bearer |
| `schemas.py` | Контракты login, refresh, logout |
| `repository.py` | Запись, поиск и отзыв refresh-токенов |
| `service.py` | Проверка пароля и жизненный цикл токенов |
| `dependencies.py` | JWT-зависимости, необязательная авторизация, require_roles |
| `router.py` | HTTP-маршруты /api/v1/auth |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
