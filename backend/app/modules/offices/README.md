# Офисы

Таблица `offices`: уникальное название и location_id. Офис служит базой бригад и владельцем складских остатков. Физическое место хранится в адресном справочнике, а не дублируется текстом.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Office и связь с Location |
| `schemas.py` | Вход и ответ офиса |
| `repository.py` | Чтение/создание офиса |
| `service.py` | Обработка бизнес-операций и отсутствующих записей |
| `router.py` | HTTP API офисов; фактические роли см. в require_roles |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
