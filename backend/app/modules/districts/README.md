# Районы

Таблица `districts`: название и city_id. Районы уникальны в пределах города. Составной ключ (id, city_id) позволяет зданию подтвердить принадлежность тому же городу, что и улица.

| Файл | Ответственность |
| --- | --- |
| `models.py` | District — район города и ограничения его уникальности |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
