# Места обслуживания

Таблица `locations`: здание, необязательные подъезд, этаж, квартира/помещение и координаты. Широта хранится в `latitude`, долгота — в `longitude`; оба столбца имеют тип `numeric(9,6)`, задаются парой и проверяются БД по диапазонам широты от -90 до 90 и долготы от -180 до 180. На одно место могут ссылаться многие заявки и офис. Уникальность адреса учитывает NULL.

При создании заявки эти координаты отправляются в Geoapify Reverse Geocoding,
если задан `GEOAPIFY_API_KEY`. Район ответа сопоставляется по городу и названию
с `districts`, затем с `service_areas`. Ответ без района или без совпадения в
справочнике не меняет адрес места и не выбирает бригаду.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Location — конкретное место обслуживания |
| `schemas.py` | Валидация адреса, координат и ответы API |
| `repository.py` | Поиск/дедупликация адресных записей через SQL |
| `service.py` | Создание адреса и сборка полного представления |
| `router.py` | HTTP-доступ к адресному справочнику |

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
