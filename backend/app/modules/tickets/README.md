# Заявки

`tickets` хранит место, название, вид работ, статус, окно визита, плановые начало/конец и оценочную/фактическую длительность. `ticket_assignments` связывает заявку с одним или несколькими исполнителями. Статусы: planned, in_progress, completed, wont_fix. Плановые времена либо оба отсутствуют, либо образуют корректную пару.

| Файл | Ответственность |
| --- | --- |
| `models.py` | Ticket, TicketAssignment, временные ограничения и индексы |
| `enums.py` | TicketStatus |
| `schemas.py` | Создание, чтение, фильтры и изменения статуса/назначений |
| `repository.py` | SQL заявок, адресов, видимости и уведомлений |
| `service.py` | Транзакции создания, назначений и смены статуса |
| `router.py` | Список/фильтры, чтение, создание и рабочий процесс |

Хранение маршрута не меняет эти строки автоматически. Отдельных полей priority,
required_transport_type и внешнего ID заявки пока нет. Совместимый импорт отражает
эту схему; сценарные отметки в синтетических данных не подменяют эти поля.

Общий API описан в [backend README](../../../README.md); ограничения существующей
системы — в [аудите](../../../../docs/AUDIT_2026-09-18.md). Миграции находятся
в [migrations](../../../migrations/README.md), проверки — в [tests](../../../tests/README.md).
