# Настройки и безопасность

`config.py` загружает переменные окружения и `.env` через Pydantic Settings,
проверяет PostgreSQL URL и кэширует объект Settings. Здесь параметры JWT, CORS,
Firebase и фоновой доставки. `security.py` хеширует/проверяет пароли Argon2,
создаёт JWT access/refresh, проверяет подпись и хеширует refresh-токены.

Образец значений находится в `../../.env.example`. Настоящие секреты не входят
в репозиторий, синтетические пакеты и документацию. Стандартный JWT-секрет
предназначен только для локального запуска: задайте собственный перед размещением.
Чтение `.env` относительно текущей директории — команды выполняются из backend.

planning_guard.py задаёт общий advisory lock для предметных изменений и применения
плана; он берётся до блокировки строк и освобождается при завершении транзакции.
body_limit.py ограничивает тело команд planning до разбора JSON.
http_limits.py ограничивает распакованное тело upstream-ответа до 4 MiB.
spreadsheet.py — общее правило пользовательского текста в CSV/XLSX: признак текста,
который таблица выполнила бы как формулу (`=`, `+`, `-`, `@`, в том числе после пробелов,
табуляций и переводов строк), недопустимые в XML символы и лимит ячейки XLSX в единицах
UTF-16. Его используют обратимый обмен данными и читаемые отчёты.
