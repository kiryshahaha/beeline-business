# Справочник синтетических данных: Москва кейса

Общий источник правдоподобных данных для всех генераторов (`generate_synthetic.py`,
`generate_acceptance_dataset.py`, `planning_scenarios.py`) и для `seed_demo.py`.

| Файл | Что содержит |
| --- | --- |
| `geography.py` | Три участка организаторов — «Восток», «Юго-восток», «Югоцентр» — с их офисами и реальными районами Москвы; деление районов между бригадами; подмосковные города «Юго-востока» (только для приёмки плана 5) |
| `buildings.json` | Реальные жилые дома этих районов и городов из OpenStreetMap |
| `people.py` | ФИО из распространённых имён, отчеств и фамилий, корпоративные логины `фамилия.ио` |
| `catalog.py` | Четыре вида работ и нормативы организаторов, навыки кейса и дополнительные компетенции, номенклатура оборудования, типы HelpDesk с долями, тексты заявок и аварий на ТКД, причины отмен, заметки |
| `fetch_osm.py` | Повторная выгрузка домов из OpenStreetMap |

## Адреса

Каждый дом в `buildings.json` — объект OpenStreetMap (`osm`: `way/…`): улица, номер дома,
корпус или строение, координаты, этажность, число квартир и подъезды. Там, где в OSM
размечены подъезды, у подъезда есть собственная точка входа и реальный диапазон квартир
(`entrance_source: "osm"`); иначе подъезды и нумерация выведены из этажности и числа
квартир (`"estimated"`), а точка — центр дома.

Заявка ставится в реальный дом: квартира берётся внутри диапазона своего подъезда, этаж
вычисляется из нумерации и этажности, координаты — точка подъезда. Авария на ТКД — это
узел дома: подъезд без квартиры. Вымышлены только сами заявки, клиенты, исполнители и
комментарии. Дома из дневных файлов организатора при выгрузке исключаются
(`--exclude-source-dir`); сами файлы в репозиторий не входят.

Данные © участники OpenStreetMap, лицензия Open Database License 1.0
(https://www.openstreetmap.org/copyright).

## Повторная выгрузка

```sh
cd backend
python -m synthetic_moscow.fetch_osm --exclude-source-dir <папка с файлами организатора>
```

Ответы Overpass кешируются в `.local/osm-cache`, повторный запуск работает без сети и даёт
тот же файл. После обновления `buildings.json` пересоздайте пакеты
(см. [data/synthetic](../../data/synthetic/README.md) и
[data/planning](../../data/planning/README.md)) и проверьте их `python verify_synthetic.py`.

## Люди и бригады

Бригада называется, как у организаторов, по бригадиру: «Бригада Кузнецов». Бригады
участка делят его районы между собой, и заявка относится к бригаде своего района.
Профили исполнителей: старший инженер (все три навыка кейса), монтажник подключений,
техник по ремонту, линейный инженер аварийной службы. Смены 10:00–22:00 и 09:00–21:00
(2/2), 09:00–18:00 и 14:00–22:00 (5/2), ночное дежурство 22:00–10:00 для аварий.
Транспорт — служебный автомобиль, общественный транспорт, пешком, велосипед.
