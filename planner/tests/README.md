# Проверки planner

Все тесты используют настоящий OR-Tools, без подмены нативной библиотеки.

- test_api_contract.py: авторизация, единственный endpoint, строгие поля и совпадение контракта backend.
- test_solve.py: максимум заявок перед сокращением пути, перегрузка смены, стоимость без обслуживания,
  второй инженер при нехватке одного, сравнение небольших задач с полным перебором.
- test_objective.py: цель политики версии 2 — авария против обычных заявок, ранний старт
  аварии, меньше инженеров при большем пути, пустые маршруты, сохранение прежних назначений,
  границы весов и переполнение; случайные малые задачи сверяются с полным перебором.
- test_t17_baseline.py: жадный ориентир и метрики T17.
- test_manual.py: разные транспорты, запрет назначения, недостижимые переходы, ожидание и ночная смена.
- fixtures.py: небольшие исходные задачи с известными ограничениями.
- generate_strong.py: печатает пример JSON без сетевых вызовов и побочных действий при импорте.

Из planner: `python -m unittest discover -s tests -v`. Обязательны все requirements.txt.
