# Матрица доступа API

Текущий контракт по ролям observer, foreman и worker. JWT проверяется на каждом
защищённом запросе, а права на заявку применяются и в списках, и при чтении по ID.

| Действие | Observer | Foreman | Worker | Без JWT |
| --- | --- | --- | --- | --- |
| Читать заявки, фильтры и адрес в карточке | Все заявки | Заявки работников своей бригады | Только назначенные ему заявки | `401` |
| Создать заявку | Да | `403` | `403` | `401` |
| Назначить исполнителей или изменить состояние заявки | Да | `403` | `403` | `401` |
| Читать, создавать и менять комментарии | Любая заявка | Своя бригада | Назначенная заявка; менять можно свой комментарий | `401` |
| Создать или получить адрес через `POST /api/v1/location` | Да | `403` | `403` | `401` |
| Скачать отчёт или выполнить обмен данными | Да | `403` | `403` | `401` |
| Читать, строить и применять планы | Да | `403` | `403` | `401` |
| Читать расписание офиса | Да | Да | `403` | `401` |
| Сохранять или рассчитывать маршруты | Да | `403` | `403` | `401` |
| Читать сохранённые маршруты | Все маршруты | Маршруты работников своей бригады | Свои маршруты | `401` |
| Выпустить, посмотреть состояние или отозвать ссылку на свой календарь | `403` | `403` | Только свой календарь | `401` |

Изменение состояния выполняет observer через команды рабочего процесса. Worker
может читать назначенную заявку и писать комментарии, но не подтверждает начало,
завершение или отмену работ. Команды назначения и события дня также требуют observer.

`GET /api/v1/schedule/calendar.ics?token=…` использует отдельный случайный секрет
из личной ссылки. Календарный клиент не отправляет JWT; сервер хранит только хеш
секрета. Uvicorn access log скрывает значения `token`, `access_token`,
`refresh_token` и `authorization` в строке запроса.

При смене пароля или фактической смене роли сервер отзывает все refresh-сессии
пользователя в той же транзакции. Текущая роль для access-запроса читается из базы.
При одновременном использовании одного refresh-токена один запрос получает новую
пару, остальные получают `401`.

`JWT_SECRET_KEY` обязателен в рабочем окружении и должен содержать не менее 32 байт.
Сгенерируйте значение командой `python -c "import secrets; print(secrets.token_urlsafe(48))"`.
