| Файл / папка | Что прочитать |
| --- | --- |
| [DATA_EXCHANGE.md](DATA_EXCHANGE.md) | Структура CSV/XLSX, импорт, экспорт, ID, безопасность и примеры |

Контракт работающего API также доступен в `/docs` и `/openapi.json` backend.
Локальные README внутри модулей объясняют соседние файлы и ограничения моделей.

При реализации трёх дополнений учитывались предоставленные материалы
`3. Билайн Бизнес.pdf` и `transcript_clean.txt`: четыре вида транспорта,
порядок посещений, время прибытия, планирование по дням, синтетические сценарии.
Полный кейс шире этих дополнений. Приоритеты заявок, автоматическое перепланирование,
карта и интеграция solver с UI не добавляются автоматически только из-за упоминания
в этих материалах.
