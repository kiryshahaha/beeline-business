# Документация Beeline Business

Beeline Business объединяет два отдельных рабочих места и общий процесс планирования. Диспетчер управляет распределением и проверяет план; инженер получает персональный маршрут и заявки; встроенный чат помогает освоить интерфейс и рабочие инструкции. Система связывает эти роли одним состоянием, экспертными ограничениями и историей опубликованных изменений.

Документы описывают устройство продукта и его сильные стороны вместе с техническими границами. Каждый материал содержит достаточно контекста для самостоятельного чтения; таблица ниже служит навигацией.

| [Архитектура](ARCHITECTURE.md) | Ответственность компонентов, общий план, безопасная публикация и чат |
