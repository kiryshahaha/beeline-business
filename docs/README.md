# Документация Beeline Business

Beeline Business — система планирования выездных инженерных работ. Документы раскрывают её назначение, работу диспетчера, архитектурные границы, ограничения алгоритма, модель данных и интеграции. Каждый материал содержит достаточно контекста для самостоятельного чтения; таблица ниже служит только навигацией.

| Раздел | Содержание |
| --- | --- |
| [Работа диспетчера](PRODUCT_WORKFLOW.md) | Заявка, исполнитель, preview, публикация и внутридневное изменение |
| [Архитектура](ARCHITECTURE.md) | Компоненты, ответственность и поток сохранения маршрута |
| [Правила планирования](PLANNING_RULES.md) | Жёсткие ограничения, приоритеты, аварии и известные границы |
| [Данные предметной области](DATA_MODEL.md) | Заявки, люди, участки, оборудование и ревизии |
| [API и внешние сервисы](API_AND_INTEGRATIONS.md) | Backend, planner, Geoapify, карты и дополнительные интеграции |
| [ИИ-помощник](ИИ-помощник.md) | Возможности, роли, источники ответов и границы помощника |

Материалы о постановке хакатона и разъяснениях экспертов собраны отдельно в папке additional_materials. Они раскрывают задачу и бизнес-контекст; технические документы выше объясняют, как система реализует рабочий процесс.
