# База знаний ассистента

Черновик. Тексты собраны по текущему API бэкенда (заявки, статусы, комментарии,
уведомления, бригады) и демо-типам работ из `backend/seed_demo.py`. Когда фронтенд
появится, формулировки про экраны и кнопки нужно сверить с интерфейсом; рекомендации
по работам — с регламентами, если организаторы их дадут.

## Формат файла

```markdown
---
title: Короткое название документа
roles: [worker, foreman, observer]
work_type: Настройка сети
---

## Раздел
Текст раздела.
```

- `roles` — кому документ показывается ассистентом. Роли совпадают с бэкендом:
  `worker` — исполнитель, `foreman` — начальник бригады, `observer` — диспетчер.
- `work_type` — необязательно. Если заявка в контексте имеет такой тип работ,
  документ добавляется в подсказку целиком, без поиска.
- Каждый раздел `##` — отдельный фрагмент поиска. Держите раздел коротким
  (до ~150 слов) и самодостаточным: маленькая модель видит только найденные фрагменты.

`README.md` в поиск не попадает.
