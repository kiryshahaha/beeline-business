## Как создать пользователя
Создавать пользователей может только диспетчер. Укажите имя, фамилию, при
необходимости отчество, логин, пароль и роль: исполнитель, начальник бригады или
диспетчер. Для исполнителя дополнительно задайте начало и конец смены и навыки.
Логин уникален без учёта регистра. Открытой регистрации в системе нет.

## Навыки
Навыки хранятся в общем справочнике, например «Монтаж ВОЛС», «Подключение абонентов»,
«Аварийно-восстановительные работы». Новый навык создаёт диспетчер, затем его можно
добавить исполнителю в профиль. Планировщик назначает заявку только исполнителю
с подходящим навыком.

## Как создать заявку
Выберите адрес из справочника (или создайте новый), укажите название, тип работ,
описание, окно визита и ожидаемую длительность в минутах. Время указывается
с часовым поясом. Конец окна визита должен быть позже начала. Новая заявка
получает статус «Запланирована».

## Как назначить исполнителей
Откройте заявку и задайте список исполнителей. Список заменяется целиком: чтобы
добавить человека, оставьте прежних и добавьте нового; чтобы снять — уберите его
из списка. Каждый новый исполнитель получает уведомление о назначении.
Назначать исполнителей может только диспетчер.

## Бригады
Диспетчер создаёт бригаду: название, начальник (пользователь с ролью «начальник
бригады») и список работников. Работник может состоять только в одной бригаде,
начальник руководит одной бригадой. Состав и начальника можно заменить целиком.
Список заявок и пользователей можно фильтровать по бригаде.

## Отброшенные заявки после планирования
Если планировщик не смог уместить заявку ни в чей маршрут (нет исполнителя с навыком,
смены не хватает, окно визита недостижимо с учётом дороги), заявка остаётся без
исполнителя. Такие заявки нужно разобрать вручную: назначить исполнителя,
согласовать с клиентом другое окно визита или добавить исполнителя с нужным навыком.
