# Материалы проекта для жюри

Beeline Business — система планирования выездных инженерных работ, связанная с ежедневной работой диспетчера и инженера.

**Ключевой замысел:** диспетчер получает проверяемый план и контролирует его публикацию; инженер — отдельный рабочий экран со своим днём, маршрутами, заявками и оборудованием; чат помогает команде освоить систему по данным и инструкциям, доступным её роли.

Наша сильная сторона — не заявление о том, что оптимизаторы существуют только у нас. Рынок уже предлагает развитые FSM-платформы. Мы выделяемся связью конкретных экспертных правил с рабочими сценариями двух ролей, безопасным внутридневным перепланированием, объяснимым preview и встроенной помощью для адаптации команды.
