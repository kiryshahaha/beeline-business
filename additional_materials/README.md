# Материалы проекта для жюри

Beeline Business — сервис планирования выездных инженерных работ. Он помогает диспетчеру согласовать заявки, исполнителей, клиентские интервалы, навыки, транспорт, оборудование и дорожное время, а затем опубликовать проверенный план с сохранением истории.

Материалы описывают одну систему с двух сторон: что требуется отраслевой задачей и как разъяснения экспертов влияют на поведение алгоритма. Они предназначены для самостоятельного чтения; каждый документ содержит собственное введение и не предполагает предварительного знакомства с исходным кодом.

- [Как решение отвечает задаче хакатона](CHALLENGE_ALIGNMENT.md)
- [Какие правила следуют из ответов экспертов](EXPERT_DECISIONS.md)

Техническое описание приложения находится в документации проекта. Здесь не приводятся тестовые учётные данные, репетиционный сценарий или неподтверждённые метрики эффективности.
