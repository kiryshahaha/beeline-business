# Beeline Business

Beeline Business помогает диспетчеру планировать выездные инженерные работы: согласовывать заявки с доступностью специалистов, клиентскими интервалами, квалификацией, транспортом, оборудованием и дорожной обстановкой.

Система состоит из веб-интерфейса, backend с бизнес-правилами, PostgreSQL и отдельного оптимизатора. Backend запрашивает дорожные оценки и геометрию у Geoapify, проверяет предложенное решение и сохраняет его только после подтверждения диспетчером.

## Как работает диспетчеризация

Диспетчер рассматривает заявки и бригады на карте и в рабочих списках. При расчёте система сначала готовит согласованный снимок данных, затем строит маршрутное предложение и возвращает причины назначений и отказов. Preview не меняет рабочий план. После проверки диспетчер применяет предложение; назначения, расписание, маршруты и новая ревизия сохраняются атомарно, а предыдущие версии остаются в истории.

Новая обычная заявка ищет свободный интервал. Авария может перестроить незавершённую часть дня после безопасного завершения текущего этапа инженера. Маршруты внутри одного участка могут охватывать разные города; назначение между разными участками запрещено.

## Локальный запуск

Нужны Docker Desktop с Compose и локальные секреты окружения. Создайте .env из шаблона, задайте пароль PostgreSQL и секрет JWT, затем запустите основные сервисы:

    Copy-Item .env.docker.example .env
    docker compose up --build -d db planner backend frontend

Для планирования дополнительно задаются PLANNING_ENABLED, общий PLANNER_SERVICE_TOKEN и GEOAPIFY_API_KEY. Секреты среды не должны попадать в Git. После запуска веб-интерфейс доступен на http://localhost:3000, документация backend API — на http://localhost:8000/docs.

## Ограничения

Качество маршрута зависит от корректных адресов и координат, заполненных справочников и доступности Geoapify. Поиск OR-Tools ограничен по времени и является эвристическим: найденный допустимый план не доказывает глобальную оптимальность. Расчётное время не является GPS-телеметрией инженера.
